# References

Drop screenshots, mood boards and notes here. The studio can see them — look at images in chat
and they become the visual bar. They are **not** loaded as project assets; assets come from studio tools into `assets/`
(the asset rule in CLAUDE.md). The one exception is an image the user asks to use in the product
(their logo, a photo): it is their file, so copy it into `assets/` and reference it from there.
